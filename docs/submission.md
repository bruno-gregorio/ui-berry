# How to Submit a Task

1. You're on Feather and you just finished a Task. On the top right there's a dropdown displaying the current state of the task. Right now it should be set to "In progress", change it to "Mark as complete".
2. The page will display a modal asking for confirmation, confirm it.
3. If things goes well, you'll see a success message and be sent to a page with other Feather tasks. If this doesn't happen in in turn you see some error message on the task page stop the workflow and inform the user immediately.
4. Close the Feather tab and go back to the the LinkedIn task tab (it's already opened).
5. There, you just need to click the "Submit" button. If things goes well, you'll be sent back to the tasks list where you can claim another task.

> Important note: this is a critical part of the workflow, if you find any unexpected circumstance outside of what's documented here, stop and inform the user.
